# EduAssistent Mobile Demo DE

Statische deutsche Demo-Version für GitHub Pages.

## Veröffentlichung auf GitHub Pages

1. Neues Repository anlegen, z. B. `eduassistent-mobile-demo-de`.
2. Dateien aus diesem ZIP hochladen.
3. In GitHub: Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, folder: `/root`.
6. Nach 1–2 Minuten öffnen:
   `https://TWOJ_LOGIN.github.io/eduassistent-mobile-demo-de/`

## QR-Code

Po opublikowaniu strony w GitHub Pages wygeneruj QR dla adresu:
`https://TWOJ_LOGIN.github.io/eduassistent-mobile-demo-de/`

Najprościej: użyj dowolnego generatora QR albo podeślij mi gotowy adres GitHub Pages, a przygotuję kod QR jako PNG.
